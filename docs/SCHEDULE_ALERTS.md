# 일정 알림 (웹 푸시) — 설계 메모

아직 만들지 않았다. 만들 때 이 문서대로 진행한다.

## 무엇을 하나
일정 시각에 아이폰 잠금 화면(홈 화면에 추가한 서랍 앱)과 맥 Safari에 알림을 띄운다. 알림을 누르면 서랍 앱이 열린다.

- 아이폰은 iOS 16.4 이상, **홈 화면에 추가한 앱**에서만 된다(Safari 탭은 안 됨).
- 기기마다 앱 안의 "알림 켜기" 버튼을 한 번 눌러 허용해야 한다(사람이 누른 버튼에서만 허용 창이 뜸).
- 웹앱이 스스로 "몇 시에 알림"을 예약하는 기능은 아이폰에 없다. 앱이 닫혀 있으면 아무것도 못 하므로, 그 시각에 **서버가 보내 줘야** 한다.

## 방식: 일정마다 그 시각에 한 번 실행 (선택함)
EventBridge **Scheduler**의 한 번 실행 예약(`at(2026-10-21T14:00:00)`, 시간대 `Asia/Seoul`)을 일정마다 하나씩 건다.

1. 일정을 저장·수정·삭제하면 API가 그 일정의 예약을 만들고·고치고·지운다.
2. 그 시각이 되면 Scheduler가 알림 함수를 실행한다.
3. 알림 함수가 저장된 기기 주소(푸시 구독)로 Apple 푸시 서버에 알림을 보낸다.
4. 실행한 예약은 `ActionAfterCompletion: DELETE`로 자동 삭제.

- 루틴(요일 반복)은 `cron(0 9 ? * MON,WED *)` 같은 반복 예약 하나.
- 하루 한 번 점검 예약 1개: 일정과 예약이 서로 맞는지 보고 빠진 예약을 만들고 남은 예약을 지운다(저장 중 오류로 어긋난 것 바로잡기).
- 사진으로 일정 들여오기(worker 완료)도 예약을 맞춰야 한다 — 일정이 바뀌는 모든 경로에서.

### 비교한 다른 방식: 1분마다 확인
고정 반복 예약 하나가 1분마다 함수를 깨워 "지금 알릴 일정"을 찾는다. 일정 경로마다 예약을 맞출 필요가 없고 어긋나도 다음 분에 맞춰져 단순하지만, 할 일이 없어도 한 달 약 4.3만 번 돈다(그래도 무료 범위). 사용자는 그 시각에만 실행하는 방식을 골랐다.

## 새로 생기는 것
| 구분 | 내용 |
|---|---|
| 앱 | 서비스 워커 파일(`sw.js`, 푸시 받기·알림 누르면 앱 열기), "알림 켜기" 버튼 |
| 데이터 | 기기별 푸시 구독(`push_subs`), 일정마다 알림 설정(정시/몇 분 전 — 아직 미정) |
| 비밀 값 | 웹 푸시 키 한 쌍(VAPID) — SSM SecureString |
| 함수 | 알림 보내기(기존 worker 컨테이너 재사용 또는 작은 함수 새로). 푸시 암호화에 `cryptography`/`pywebpush` 필요 → 컨테이너가 편함 |
| Scheduler | 예약 그룹 1개(예: `<prefix>-alerts`), 일정마다 한 번 실행 예약, 루틴 반복 예약, 하루 한 번 점검 예약 |
| IAM | ① Scheduler가 알림 함수를 실행할 역할(신뢰: `scheduler.amazonaws.com`, 권한: 그 함수 `lambda:InvokeFunction`) ② API 함수 역할에 그 예약 그룹 안에서만 `scheduler:CreateSchedule`·`UpdateSchedule`·`DeleteSchedule`·`GetSchedule`·`ListSchedules`, ①역할에 대한 `iam:PassRole` ③ 배포용으로 위를 만드는 임시 권한(콘솔에서 사용자가 붙였다 떼기) |

## 비용 (AWS 공식 가격표 기준)
- EventBridge Scheduler: 매달 1,400만 번까지 무료(12개월 제한 없음), 넘으면 100만 번당 1.00달러. 크기와 무관하게 실행 횟수로만 셈. [가격표](https://aws.amazon.com/eventbridge/pricing/)
- 예상 사용량: 알림 한 달 수십~수백 번 + 점검 30번 → 무료 한도의 0.01% 미만, **0원**.
- 알림 함수(Lambda): 한 번 1초 미만. 지금 Lambda 사용량(무료 한도의 약 3%)에 거의 안 더해짐.
- Apple 푸시 서버: 무료.
- 지금 쓰는 EventBridge 규칙(worker 1시간 깨우기)은 공식 페이지에 시간 예약 규칙 요금이 따로 적혀 있지 않지만, 실제 청구서(비용 탐색기)에 EventBridge 항목이 없음.

## 만들 때 정할 것
1. 언제 알릴지: 정시 / 10분 전 / 일정마다 고르기
2. 어떤 일정: 약속·예약만 / 루틴까지 / 할 일(시간이 없어 "마감일 아침 몇 시" 기준 필요)

## 순서(만들 때)
1. 정할 것 확정 → 권한 파일(`data/iam/…`, 커밋 안 함)과 배포 스크립트 작성.
2. 사용자가 임시 권한 붙임 → 키·역할·예약 그룹·함수 배포 → 임시 권한 뗌.
3. 아이폰 홈 화면 앱에서 "알림 켜기" → 1~2분 뒤 일정으로 시험 → 잠금 화면 알림·누르면 앱 열림 확인.
