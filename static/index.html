아이폰 단축어 다운로드 단축어 v12

다운로드한 파일을 열어 단축어에 추가하고 접속 키를 한 번 입력하세요. 바로 열리지 않으면 파일 앱의 다운로드 폴더에서 열어 주세요.

SNS 링크 또는 사진 앱에서 공유 → 서랍에 저장(링크·사진 v12)를 선택하세요. 사진만 공유해도 됩니다. 기존 버전이 있으면 새 버전으로 교체하세요.

맥에서는 공유 메뉴로 써도 되고, 링크를 복사한 뒤 단축어를 바로 실행해도 클립보드의 링크가 저장됩니다. 저장 후 "서랍에서 보기"를 누르면 방금 저장한 카드로 이동합니다.

웹 주소는 항상 입니다. 화면이 이전 상태라면 새로고침해 주세요.

웹과 단축어에 같은 접속 키를 입력합니다.

분류·요약은 저장 후 자동으로 진행됩니다. 읽을 수 없는 본문은 카드에서 추가할 수 있습니다.
