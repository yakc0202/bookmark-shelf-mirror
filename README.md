# 서랍 · Link Shelf

아이폰 공유 메뉴 → 단축어 → S3 + Lambda → Codex/Claude 분류·요약 → 웹 카드(북마크)와 메모.
Route53·EC2·API Gateway 없이 **S3 + CloudFront(HTTPS) + Lambda Function URL + 서버리스 Lambda 워커(컨테이너 이미지)**로 운영하는 현재(클라우드) 버전입니다.
아키텍처·환경 설정·API·데이터 모델·배포 명령은 [`SETUP.md`](SETUP.md)를 참고하세요.

```
아이폰·맥 공유 메뉴(단축어) ──▶ api Lambda(Function URL) ──▶ S3 데이터 파일 (ETag 조건부 쓰기)
                                    │  "대기" 카드 저장 후 worker 깨우기
                                    ▼
                              worker Lambda(컨테이너) ──▶ Codex/Claude CLI: 제목·요약·폴더·태그(JSON 스키마)
                                    │  결과를 api로 보냄          ▲
                                    ▼                              └─ EventBridge 1시간마다(밀린 작업 안전망)
브라우저 ──▶ CloudFront(접속 키 확인 함수) ──▶ S3 화면 파일 · 사진
         └─ /s/<토큰> 공유 링크 ──▶ api (읽기 전용, 잠금 없음)
```

## 빠른 사용법

1. [`SETUP.md`](SETUP.md)대로 S3 버킷/Lambda(api + worker)를 배포하고 `data/token` 등 비밀 파일을 로컬에 준비합니다.
2. 배포한 웹 주소에서 접속 키를 입력해 연결합니다.
3. 아이폰 단축어(`shortcuts/`)를 설치하고 같은 접속 키를 입력하면 공유 메뉴에서 바로 저장됩니다.

저장 직후 서버리스 Lambda 워커가 자동으로 AI 분류·요약·메모 발췌를 처리합니다. 맥을 켜둘 필요는 없습니다. 로컬 워커(`cloud/worker.py`, `./start-cloud.command`)는 Lambda 워커 전환을 검증한 뒤 완전히 중지했고, 지금은 쓰지 않습니다.

## 현재 지원 범위

- **서랍(북마크)**: 아이폰·맥 단축어로 링크·사진 공유 저장(저장 뒤 알림만, 앱을 열면 방금 저장한 카드로 이동해 강조), 중복 확인, 이어진 글(타래) 자동 묶기, 모음(묶기·전환·개별 북마크로 나누기), 사진 합치기, 삭제·복원, 별표(별표한 것만 모아 보기), 폴더 대분류/하위 분류(상위 폴더를 누르면 하위 폴더 카드까지 함께, 하위 폴더는 이름만 표시), 펼친 모음은 다른 화면에 다녀오면 접힘, 유형별 보기, 검색, 페이지 넘김(« 처음), 카드 옆으로 밀어 메뉴
- **AI 정리**: Codex 1 → Codex 2 → Claude 1 → Claude 2 순서로 제목·요약·폴더·태그 생성(실패한 계정은 1시간, 로그인 실패는 하루 건너뜀), X 글은 FxTwitter 공개 API로 본문·아티클 읽기(못 읽으면 추측 없이 "내용 필요"), 유튜브는 공식 oEmbed로 제목·채널, 내용이 부족하면 태그 떼기, 사진 글자 전사, 위치 모르는 가게는 웹 검색으로 도시 채우기, 모음 주제 추론, 행사 종료일 추출 → 지난 행사 폴더, 사진·링크가 덧붙으면 다시 정리
- **공유 링크**: 북마크·모음(담긴 항목 전체) 읽기 전용 공유, 개인 메모 비공개, CloudFront 기본 주소의 별도 경로(도메인을 바꿔도 유지)
- **메모**: 북마크 끌어 넣기, 사진 붙여 넣기, 소제목 목차, 체크리스트, AI 발췌, 요약 버튼
- **일정**: 오늘(마감 7일 이내 할 일·일정), 할 일(마감), 달력(입사지원 일정 보기 토글), 해빗트래커, 운동(이용권·예약, 예약 앱 캡처 AI 인식, 예약 대기), 복사해서 만들기
- **가계부**: 5일~다음 달 4일 기간, 달력, 분류별 지출(누르면 그 분류 내역 전체), 지출 계획(체크하면 지출로 기록, 그 지출을 고치면 계획 금액도 같이 바뀜), 공용 통장(데이터 분리), 위시리스트(링크 담기, 사진에서 상품 AI 인식)

## 운영 장치

- **동시 저장**: 데이터 파일 쓰기는 S3 ETag 조건부 PUT으로 하고, 충돌하면 다시 읽어 최대 8회 재시도합니다.
- **작업권**: worker는 카드를 10분 작업권(lease)으로 가져가고, 만료되면 대기로 돌립니다. 처리 중 글이 덧붙으면 다시 대기로 돌려 바로 재처리합니다.
- **AI 폴백**: 계정 하나가 실패하면 이유와 상관없이 다음 계정으로 넘기고, 로그인 정보는 실행마다 SSM에서 읽고 갱신 값을 다시 저장합니다.
- **인증**: 사이트는 CloudFront Function이 접속 키를 확인한 뒤에만 열고, api는 모든 요청(공유 링크 제외)의 키 해시를 다시 확인합니다.
- **권한**: IAM은 실제로 쓰는 리소스에만 맞춘 정책 하나로 운영합니다. 일회성 작업 권한은 필요할 때 붙였다가 뗍니다.
- **공개 미러**: 계정·리소스 ID, 엔드포인트, 키, 도메인을 가린 사본만 내보내고, 가릴 모양이 남으면 push하지 않습니다(`mirror-push.sh`).
- **시험**: `tests/`에 194개 시험(저장·병합·정리·공유·가계부 등)이 있습니다.

아직 없음: 플랫폼별 공식 API 인증, 영상 다운로드·음성 전사, 여러 장짜리 피드 사진 자동 수집.
영상 자체를 분석하지 않으며 모든 요약은 확보한 웹 본문·공유 텍스트·사진 기반입니다.
