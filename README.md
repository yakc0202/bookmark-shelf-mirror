# 서랍 · Link Shelf

아이폰 공유 메뉴 → 단축어 → S3 + Lambda → Codex/Claude 분류·요약 → 웹 카드(북마크)와 메모.
Route53·EC2·API Gateway 없이 **S3 + CloudFront(HTTPS) + Lambda Function URL + 서버리스 Lambda 워커(컨테이너 이미지)**로 운영하는 현재(클라우드) 버전입니다.
아키텍처·환경 설정·API·데이터 모델·배포 명령은 [`SETUP.md`](SETUP.md)를 참고하세요.

## 빠른 사용법

1. [`SETUP.md`](SETUP.md)대로 S3 버킷/Lambda(api + worker)를 배포하고 `data/token` 등 비밀 파일을 로컬에 준비합니다.
2. 배포한 웹 주소에서 접속 키를 입력해 연결합니다.
3. 아이폰 단축어(`shortcuts/`)를 설치하고 같은 접속 키를 입력하면 공유 메뉴에서 바로 저장됩니다.

저장 직후 서버리스 Lambda 워커가 자동으로 AI 분류·요약·메모 발췌를 처리합니다. 맥을 켜둘 필요는 없습니다. 로컬 워커(`cloud/worker.py`, `./start-cloud.command`)는 Lambda 워커 전환을 검증한 뒤 완전히 중지했고, 지금은 쓰지 않습니다.

## 현재 지원 범위

- **서랍(북마크)**: 아이폰·맥 단축어로 링크·사진 공유 저장, 중복 확인, 이어진 글(타래) 자동 묶기, 모음(묶기·전환·개별 북마크로 나누기), 사진 합치기, 삭제·복원, 폴더 대분류/하위 분류, 유형별 보기, 검색, 페이지 넘김(« 처음), 카드 옆으로 밀어 메뉴
- **AI 정리**: Codex 1 → Codex 2 → Claude 1 → Claude 2 순서로 제목·요약·폴더·태그 생성(실패한 계정은 1시간, 로그인 실패는 하루 건너뜀), 사진 글자 전사, 위치 모르는 가게는 웹 검색으로 도시 채우기, 모음 주제 추론, 행사 종료일 추출 → 지난 행사 폴더, 사진·링크가 덧붙으면 다시 정리
- **공유 링크**: 북마크·모음(담긴 항목 전체) 읽기 전용 공유, 개인 메모 비공개, CloudFront 기본 주소의 별도 경로(도메인을 바꿔도 유지)
- **메모**: 북마크 끌어 넣기, 사진 붙여 넣기, 소제목 목차, 체크리스트, AI 발췌, 요약 버튼
- **일정**: 오늘(마감 7일 이내 할 일·일정), 할 일(마감), 달력(입사지원 일정 보기 토글), 해빗트래커, 운동(이용권·예약, 예약 앱 캡처 AI 인식, 예약 대기), 복사해서 만들기
- **가계부**: 5일~다음 달 4일 기간, 달력, 지출 계획(체크하면 지출로 기록), 공용 통장(데이터 분리), 위시리스트(링크 담기, 사진에서 상품 AI 인식)
- **화면**: 노트 스타일, 앱 확인 창(사파리 기본 창 대신), 날짜 달력·시간 직접 입력, 아이폰 홈 화면 앱(맥은 설치 안내 없음), 접속 키 잠금(CloudFront Function)

아직 없음: 플랫폼별 공식 API 인증, 영상 다운로드·음성 전사, 여러 장짜리 피드 사진 자동 수집.
영상 자체를 분석하지 않으며 모든 요약은 확보한 웹 본문·공유 텍스트·사진 기반입니다.
원본 내용은 분류를 위해 로그인된 Codex 또는(한도 초과 시) Claude Code로 전송됩니다. 인증 키나 쿠키는 게시물 수집에 사용하지 않습니다.

## OLD: 로컬 전용 모드 (초기 프로토타입, 더 이상 사용하지 않음)

아래는 S3/Lambda로 옮기기 전, 맥 로컬 서버 + Tailscale만으로 운영하던 초기 버전의 안내입니다.
`server.py`를 직접 실행하는 이 모드는 코드에 남아 있지만 현재 운영 방식이 아니므로 새로 시작한다면 위 "빠른 사용법"을 따르세요.

### 실행

`start.command`를 실행하고 http://localhost:8787 에 접속합니다.
접속 키는 `data/token` 파일에 있으며 브라우저에 한 번 입력합니다.
Codex CLI에 로그인되어 있어야 자동 분류가 작동합니다.
카드와 대기열은 `data/shelf.db`에 저장됩니다.

### 외부 공유 연결 (Tailscale)

1. https://tailscale.com/download 에서 맥·아이폰용 Tailscale을 설치합니다.
2. 양쪽에서 같은 계정으로 로그인하고 연결합니다.
3. 맥의 Tailscale IP로 `http://100.x.x.x:8787`를 아이폰 Safari에서 엽니다.
4. 접속 키로 연결한 뒤 웹 화면 상단의 '연결 안내'대로 단축어를 만듭니다.
5. 아이폰 Wi-Fi를 끄고 셀룰러에서 링크를 공유해 실제 외부 연결을 확인합니다.

수신 주소: `http://맥의-Tailscale-IP:8787/api/items`
메서드: POST / JSON 본문: `{"text":"단축어 입력의 텍스트"}`
헤더: `Authorization: Bearer 접속키`

이 HTTP 주소는 개인 Tailscale 연결용입니다. 공유기 포트 개방이나 공개 터널로 노출하지 마세요.
서버 실행 중 caffeinate가 유휴 잠자기를 막습니다. 덮개 닫기·종료·네트워크 단절 때는 이용할 수 없습니다.
